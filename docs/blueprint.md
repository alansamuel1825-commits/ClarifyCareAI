# **App Name**: ClarifyCare AI

## Core Features:

- Smart Document Processor: Scan documents, upload PDFs, or paste text to have the AI analyze the content using reasoning as a tool to determine the nature of the assistance needed.
- The 'Plain Talk' Explainer: Converts complex bureaucratic or technical language into a simple, high-readability summary for easy comprehension.
- Intelligent Deadline Extractor: An AI tool that scans the text to extract critical dates and automatically generates a prioritized action checklist.
- Urgency & Risk Evaluator: Uses LLM logic as a tool to categorize document urgency from Low to High, while detailing the consequences of inaction.
- Resource Connection Engine: Recommends local support resources, counselors, and community programs based on the specific document context.
- Support Dashboard & Tracker: Allows users to save document analyses, track completed actions, and store progress history securely in Firestore.
- Inclusion Accessibility Panel: Toggle between high-contrast mode, large text, and voice synthesis outputs for users with varying visual or reading needs.

## Style Guidelines:

- Primary color: Trustworthy Deep Blue (#2444A8) to evoke a sense of professional reliability.
- Background color: A serene and clean light-gray wash (#F1F3F6) to reduce visual fatigue during stressful reading tasks.
- Accent color: Accessible Teal-Azure (#239BC2) for call-to-action buttons, providing distinct contrast against the primary blue.
- Headline font: 'Inter' for a machined, objective, and neutral feel that aids professional clarity. Body font: 'PT Sans' to add a humanist warmth and improve readability across varied text sizes.
- Minimalist, thin-stroke icons that represent empathy and support, using consistent weighting for clear recognition.
- A spacious, mobile-first dashboard layout utilizing clean white cards with generous padding for a professional and uncrowded feel.
- Calm, gentle fade-ins when document summaries load to minimize the feeling of overwhelming the user with new information.
